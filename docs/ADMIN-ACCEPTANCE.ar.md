# تجربة أمجد قبل نشر الموقع

> اعتمد صاحب الموقع قواعد الحذف النهائي والدمج والنشر بعد نجاح الفحوص، ونُشرت القواعد. التعليمات التالية للتجربة البشرية دون مشاركة كلمة المرور؛ لا يُستخدم أمجد الحقيقي في الاختبارات الآلية. الحالة الحالية في `docs/FINAL-RELEASE-PR2.ar.md`.

القواعد الإنتاجية المحددة منشورة ومتحقق من بصمتها. PR #2 لم يُدمج والواجهة العامة لم تُنشر.

1. من اللابتوب نفسه افتح رابط المعاينة المحلية الخاص بالإدارة الذي يقدمه Codex.
2. ألغِ «تذكرني» في هذه التجربة، وسجّل الدخول بحساب أمجد الحالي بنفسك. لا ترسل كلمة المرور في المحادثة.
3. تأكد من ظهور إدارة الأعضاء والعهد وسؤال وجواب والمكتبة، وافتح كل قسم للتأكد من تحميله.
4. أخبرنا هل نجح الدخول وظهرت القوائم. لا يلزم إنشاء عضو أو حذف بيانات لإثبات نجاح الدخول. سجّل الخروج بعد التجربة.

هذه معاينة ملفات محلية تتصل بمشروع `tribe-app-e3e9c` الحقيقي عبر Firebase Client SDK فقط، وليست المحاكي. أي تعديل تنفذه بنفسك فيها بعد الدخول يُحفظ في الإنتاج وفق صلاحيات أمجد.
الخادم مربوط بـ `127.0.0.1` فقط، ولا يُتاح للهاتف عبر الشبكة أو للجمهور، ولا يحتوي رموز OAuth إدارية أو مفاتيح خدمة أو أي endpoint يستقبل كلمة المرور.
كلمة المرور تُرسل من متصفحك إلى Firebase عبر HTTPS، ولا تُكتب في ملفات المعاينة أو سجلات الخادم. هذه المعاينة لا تقرأ تخزين موقع GitHub Pages، ولا تنقل بيانات الضيف أو تستوردها.
تبقى نسخة المحاكي السابقة متاحة للاختبارات الوهمية، ولا تُستخدم بيانات دخولها في تجربة أمجد الحقيقية.

موافقة الدمج والنشر المشروطة مُنحت بالفعل. بعد نجاح النشر افتح صفحة الإدارة الدائمة `https://ramadan258.github.io/admin.html` لتجربة دخول أمجد بنفسك، دون رابط لها داخل الواجهة العامة ودون مشاركة كلمة المرور.
